# Объяснение проекта: FSM-враги в Unity 2D

## Что сделано

### Состояния (FSM — конечный автомат)
> **Конечный автомат** — это когда объект всегда находится ровно в одном состоянии из заранее заданного списка, и переходит между ними по правилам.

| Состояние | Что делает враг | Файл |
|-----------|-----------------|------|
| **Idle** | Стоит на месте, ждёт `idleWaitTime` секунд | `EnemyBasic.cs` → `UpdateIdle()` |
| **Patrol** | Ходит по массиву `patrolPoints` по очереди | `EnemyBasic.cs` → `UpdatePatrol()` |
| **Chase** | Бежит к игроку каждый кадр | `EnemyBasic.cs` → `UpdateChase()` |
| **Attack** | Стоит, наносит урон с задержкой `attackCooldown` | `EnemyBasic.cs` → `UpdateAttack()` |
| **Search** | Идёт к последней известной позиции, ждёт `searchTime` | `EnemyBasic.cs` → `UpdateSearch()` |
| **Teleport** | Только у EnemyTeleporter — мигает и перемещается к игроку | `EnemyTeleporter.cs` → `TeleportRoutine()` |

### Движение в 8 направлениях
- Файл: `EnemyBasic.cs` → `Move8Dir()`
- Алгоритм: считаем угол к цели → округляем до кратного 45° → превращаем обратно в вектор → ставим в `rb.linearVelocity`

### Обзор 180° (конус видимости)
- Файл: `EnemyBasic.cs` → `CanSeePlayer()`
- Три условия одновременно: расстояние ≤ `detectRange`, угол ≤ 90° от направления взгляда, Raycast не упирается в стену

### Raycast
- Файл: `EnemyBasic.cs` → `CanSeePlayer()`, `EnemyTeleporter.cs` → `DoScan()`
- **Raycast** — это луч, который Unity пускает в сцене и возвращает, во что он попал. Если луч дошёл до игрока без препятствий — враг его видит.

### Скан 360° у телепортёра
- Файл: `EnemyTeleporter.cs` → `DoScan()`
- Раз в `scanInterval` секунд ищет все объекты в круге радиуса `scanRadius`, из них выбирает игрока и проверяет Raycast. Угол не ограничен — полный круг.

### Телепорт
- Файл: `EnemyTeleporter.cs` → `TeleportRoutine()`, условие в `Update()`
- Мигает (спрайт скрывается на 0.2 с), перемещается рядом с игроком, перезарядка `teleportCooldown`

### Атака с визуальной обратной связью
- Файл: `EnemyBasic.cs` и `EnemyTeleporter.cs` → `DoAttack()` + `FlashRed()`
- Вызывает `PlayerHealth.TakeDamage()`, спрайт краснеет на 0.1 с

### Уровень (Tilemap)
- Файл: `Assets/Editor/TopDownSceneBuilder.cs` → `Build()`
- Комната 20×14 тайлов, стены по периметру, 5 препятствий 2×2 внутри

### Камера
- Устанавливается в `TopDownSceneBuilder.Build()`: `orthographicSize = 7f`, видит всю комнату целиком

### Управление игроком
- Файл: `Assets/Scripts/Player/PlayerController.cs`
- WASD/стрелки, 8 направлений, нормализованный вектор, `rb.linearVelocity`

## Что НЕ сделано или сделано упрощённо

| Что | Почему |
|-----|--------|
| Анимации (Idle/Run) не переключаются | Нет Animator на объектах — только статичный спрайт |
| Звук | Не требовалось по заданию |
| EnemyTeleporter практически слеп | `scanRadius = 1` — требование задания "ровно 1 юнит". Нужно подойти вплотную |
| Телепорт срабатывает не всегда | Если точка назначения в стене — телепорт отменяется |
| Нет интерфейса HP на экране | Не требовалось |

## Как устроен код

### PlayerController.cs (37 строк)

```csharp
void Update()
{
    float h = Input.GetAxisRaw("Horizontal"); // -1, 0 или 1 от WASD/стрелок
    float v = Input.GetAxisRaw("Vertical");

    Vector2 dir = new Vector2(h, v);
    if (dir.sqrMagnitude > 1f) dir.Normalize(); // диагональ не быстрее прямой

    rb.linearVelocity = dir * moveSpeed;         // двигаем физикой

    if (h > 0)      sr.flipX = false; // смотрим вправо
    else if (h < 0) sr.flipX = true;  // смотрим влево
}
```

**Зачем нормализация?** Если нажать вправо и вверх одновременно, вектор (1,1) имеет длину ≈1.41 — персонаж едет быстрее. `Normalize()` делает длину ровно 1.

### PlayerHealth.cs (27 строк)

```csharp
public void TakeDamage(int amount)
{
    if (invincibleTimer > 0f) return;      // ещё неуязвим — пропускаем
    hp -= amount;
    invincibleTimer = invincibleTime;      // включаем неуязвимость
    if (hp <= 0) SceneManager.LoadScene(SceneManager.GetActiveScene().buildIndex);
}
```

**Неуязвимость** нужна чтобы враг не снимал всё HP за один кадр касания.

### EnemyBasic.cs (185 строк)

#### Главный цикл

```csharp
void Update()
{
    if (attackTimer > 0f) attackTimer -= Time.deltaTime; // отсчёт кулдауна атаки
    switch (currentState)
    {
        case State.Idle:   UpdateIdle();   break;
        case State.Patrol: UpdatePatrol(); break;
        case State.Chase:  UpdateChase();  break;
        case State.Attack: UpdateAttack(); break;
        case State.Search: UpdateSearch(); break;
    }
}
```

`switch` по состоянию — каждый кадр запускается один нужный метод.

#### Вход в состояние

```csharp
void EnterState(State s)
{
    currentState = s;
    stateTimer   = 0f; // сбрасываем таймер при каждом переходе
    if (s == State.Idle || s == State.Search)
        rb.linearVelocity = Vector2.zero; // останавливаемся
}
```

#### Пример переходов в Chase

```csharp
void UpdateChase()
{
    float dist = Vector2.Distance(transform.position, player.position);
    lastKnownPos = player.position; // запоминаем где был игрок

    if (dist <= attackRange)                  { EnterState(State.Attack); return; }
    if (dist > loseRange || !CanSeePlayer())  { EnterState(State.Search); return; }

    Move8Dir(player.position); // продолжаем гнаться
}
```

#### Движение в 8 направлениях

```csharp
void Move8Dir(Vector2 target)
{
    Vector2 dir   = (target - (Vector2)transform.position).normalized;
    // Atan2 даёт угол по координатам. Делим на 45, округляем, умножаем — кратный 45°.
    float   angle = Mathf.Round(Mathf.Atan2(dir.y, dir.x) * Mathf.Rad2Deg / 45f) * 45f;
    float   rad   = angle * Mathf.Deg2Rad;
    Vector2 moveDir = new Vector2(Mathf.Cos(rad), Mathf.Sin(rad));
    rb.linearVelocity = moveDir * moveSpeed;
}
```

### EnemyTeleporter.cs (229 строк)

Структура та же, плюс:

#### Периодический скан в Update

```csharp
scanTimer += Time.deltaTime;
if (scanTimer >= scanInterval) { scanTimer = 0f; DoScan(); }
```

Не каждый кадр, а раз в `scanInterval` секунд.

#### Условие телепорта

```csharp
float d = Vector2.Distance(transform.position, player.position);
if (d >= teleportMinDistance && d <= maxTeleportDistance && teleportTimer <= 0f)
    EnterState(State.Teleport);
```

Телепорт только если игрок в нужном диапазоне расстояний и кулдаун прошёл.

#### Корутина телепорта

**Корутина** — метод, который может делать паузу и продолжать работу после. Обычный метод так не умеет.

```csharp
IEnumerator TeleportRoutine()
{
    isTeleporting = true;
    Vector2 targetPos = (Vector2)player.position + dirToEnemy * teleportArrivalDist;

    // Проверяем нет ли стены в точке назначения
    if (Physics2D.OverlapCircle(targetPos, 0.2f, obstacleLayer) != null)
    { teleportTimer = teleportCooldown; isTeleporting = false; yield break; }

    sr.enabled = false;                    // скрываем спрайт
    yield return new WaitForSeconds(0.2f); // ждём 0.2 секунды
    transform.position = targetPos;        // перемещаемся
    sr.enabled = true;                     // показываем спрайт
    isTeleporting = false;
    EnterState(State.Chase);
}
```

## Как работает обнаружение

### EnemyBasic — конус 180°

```csharp
bool CanSeePlayer()
{
    Vector2 toPlayer = (Vector2)player.position - (Vector2)transform.position;
    float   dist     = toPlayer.magnitude;
    if (dist > detectRange) return false;                          // 1. дистанция
    if (Vector2.Angle(facingDir, toPlayer) > 90f) return false;   // 2. сектор 180°
    return Physics2D.Raycast(transform.position,
        toPlayer.normalized, dist, obstacleLayer).collider == null; // 3. нет стены
}
```

`facingDir` — направление взгляда (`Vector2.right` или `.left`), обновляется при движении. `Vector2.Angle` возвращает угол между двумя векторами. Если больше 90° — игрок сзади.

### EnemyTeleporter — скан 360°

```csharp
void DoScan()
{
    foreach (Collider2D col in Physics2D.OverlapCircleAll(transform.position, scanRadius))
    {
        if (!col.CompareTag("Player")) continue;
        bool blocked = Physics2D.Raycast(...).collider != null;
        if (!blocked) playerKnown = true;
    }
}
```

**Отличие:** нет проверки угла — полный круг, но скан раз в 1.5 с, и `scanRadius = 1` (очень маленький). Обнаруживает только если игрок вплотную.

## Как работает телепорт

**Условие:** Chase + `[teleportMinDistance ≤ dist ≤ maxTeleportDistance]` + кулдаун = 0

**Точка назначения:** `позиция игрока + (от игрока к врагу) × teleportArrivalDist` — рядом с игроком, не прямо в нём.

**Защита от стен:** `Physics2D.OverlapCircle(targetPos, 0.2f, obstacleLayer)` — если в точке назначения есть стена, телепорт отменяется, кулдаун сбрасывается.

**Флаг `isTeleporting`:** корутина работает несколько кадров. Флаг не даёт запустить вторую корутину пока первая не закончила.

| Объект | Компоненты | Зачем |
|--------|------------|-------|
| **Player** | `Rigidbody2D`, `CircleCollider2D`, `PlayerController`, `PlayerHealth` | Управляемый персонаж |
| **EnemyBasic** | `Rigidbody2D`, `CircleCollider2D`, `EnemyBasic` | Враг с конусом видимости |
| **EnemyTeleporter** | `Rigidbody2D`, `CircleCollider2D`, `EnemyTeleporter` | Враг-телепортёр |
| **Grid/Tilemap_Walls** | `Tilemap`, `TilemapCollider2D`, `CompositeCollider2D`, `Rigidbody2D Static` | Стены с физикой |
| **Grid/Tilemap_Floor** | `Tilemap`, `TilemapRenderer` | Пол без коллайдера (декорация) |
| **Background** | `SpriteRenderer (Tiled)` | Фон из Pixel Adventure |
| **Main Camera** | `Camera Orthographic, size=7` | Камера сверху |

### Слои и теги

- Тег **"Player"** на игроке — враги находят его через `FindGameObjectWithTag("Player")`
- Слой **"Obstacle"** на `Tilemap_Walls` — Raycast и OverlapCircle ищут именно этот слой через `LayerMask`

### Tilemap и коллизии

**Tilemap** — сетка спрайтов. Вместо сотни объектов-стен — один Tilemap с тайлами.

**CompositeCollider2D** объединяет коллайдеры всех тайлов в один контур. Цепочка:
```
TilemapCollider2D (compositeOperation = Merge)
    ↓ передаёт данные
CompositeCollider2D (собирает в единый контур)
    ↓ требует
Rigidbody2D (bodyType = Static)
```

### Где менять параметры

Кликни объект в Hierarchy → Inspector:

| Параметр | Объект | Что изменится |
|----------|--------|---------------|
| `detectRange` | EnemyBasic | Радиус жёлтого круга Gizmo, дальность обнаружения |
| `attackRange` | EnemyBasic | Дальность атаки |
| `moveSpeed` | EnemyBasic / EnemyTeleporter | Скорость движения |
| `scanRadius` | EnemyTeleporter | Радиус скана 360° |
| `teleportCooldown` | EnemyTeleporter | Пауза между телепортами |
| `hp` | Player → PlayerHealth | Начальные очки жизни |
| `moveSpeed` | Player → PlayerController | Скорость игрока |

## Как запустить и что показывать на видео

1. В Unity открыть меню **Tools → Build TopDown LabScene**
2. Дождаться диалога «Готово»
3. Нажать **▶ Play**
4. Управление: **WASD** или **стрелки**

**Сценарий для видео:**
- Игрок ходит во все 8 направлений, упирается в стены
- EnemyBasic патрулирует → замечает игрока в конусе → преследует → атакует (краснеет)
- Игрок уходит за угол-препятствие → враг переходит в Search → идёт к последней точке
- EnemyTeleporter патрулирует → игрок подходит вплотную → телепорт (мигает)
- Игрок получает урон до 0 HP → сцена перезапускается

## Шпаргалка к защите

**В: Что такое конечный автомат и как он реализован?**  
О: Объект всегда в одном состоянии из списка. В коде — `enum State`, переменная `currentState`, `switch` в `Update()` вызывает нужный метод. Переход — вызов `EnterState()`.

**В: Почему Raycast, а не просто расстояние?**  
О: Расстояние не учитывает стены. Raycast — луч, который упирается в стену раньше игрока → враг не видит цель за укрытием.

**В: Как работает сектор 180°?**  
О: `Vector2.Angle(facingDir, toPlayer)` — угол между взглядом и вектором к игроку. Больше 90° — игрок сзади, не виден. Два по 90° дают 180°.

**В: Чем отличается обнаружение у двух врагов?**  
О: EnemyBasic: каждый кадр, только 180° перед собой. EnemyTeleporter: раз в 1.5 с, полный круг 360°, но радиус всего 1 юнит — нужно подойти вплотную.

**В: Как телепорт защищён от попадания в стену?**  
О: `Physics2D.OverlapCircle(targetPos, 0.2f, obstacleLayer)` — если в точке назначения есть стена, телепорт отменяется.

**В: Зачем флаг `isTeleporting`?**  
О: Корутина работает несколько кадров. Без флага `Update()` мог бы запустить вторую корутину. Флаг блокирует повторный запуск.

**В: Как CompositeCollider2D связан с Tilemap?**  
О: TilemapCollider2D делает коллайдер на каждый тайл. CompositeCollider2D объединяет их в один контур — это быстрее и корректно работает с Raycast.
